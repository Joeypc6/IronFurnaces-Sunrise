# Machine Work

Machine Work es un mod biblioteca pequeño: una máquina cuenta a otros mods cuánto le falta y cuánto tarda una operación. Estos hornos responden:

- **progress**: la fundición en curso; en una fábrica la fila más cerca de terminar, con las filas activas.
- **pace**: lo que tarda ahora una fundición de un objeto, con cuántos funde a la vez.
- Un generador, o un horno parado por redstone, no responde.

El [tiempo restante de AE2](ae2_eta.md) lo consulta primero.
