# Aspectos del horno

- Haz clic derecho en un horno con <ItemLink id="item_spooky" /> para un aspecto terrorífico.
- Con <ItemLink id="item_xmas" /> lo envuelves como un regalo.
- El objeto no se gasta; solo cambia el aspecto.
- Agáchate y haz clic derecho con la mano vacía para deshacerlo.
