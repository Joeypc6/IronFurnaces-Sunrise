# Furnace looks

- Right-click a furnace with <ItemLink id="item_spooky" /> for a spooky look.
- Right-click with <ItemLink id="item_xmas" /> to wrap it as a gift.
- The item isn't used up; only the look changes.
- Sneak and right-click with an empty hand to undo.
