# Config file

Server owners can change the numbers in `config/ironfurnaces.toml`; this guide shows the defaults.

- `iron_furnace.speed` (each furnace): ticks per smelt.
- `iron_furnace.generation`: generator RF/t.
- `iron_furnace.tier`: 0, 1 or 2, for factory rows and buffer.
- `energy.tier_0`, `energy.tier_1`, `energy.tier_2`: the buffers.
- `allthemodium_furnace.mult` (and Vibranium, Unobtainium): smelts at once, up to 64.
- `rainbow_furnace.rainbow_generation`: the Rainbow generator's RF/t.
- `misc.lightupdates = true`: furnaces give no light.
